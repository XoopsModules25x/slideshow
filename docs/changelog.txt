XOOPS Slideshow Module — Changelog
===================================

v2.10 (2025-06-01)
------------------
BUGFIXES
  - deleteitem: XOOPS_URL → XOOPS_ROOT_PATH; file deletion now works
  - edititem / addcategory: switched to $_POST (was $_REQUEST)
  - edititem: image re-upload now works during edit; existing image kept if
    no new file is provided
  - itemBlockList(): date-range filter now applied at DB level; expired /
    future-scheduled slides no longer shown in blocks
  - Normalised item_type default to 'image'; old 'slideshow' values migrated
  - TIMESTAMP columns no longer use ON UPDATE (dates were reset on every save)
  - MyISAM → InnoDB for both tables
  - Category loop re-written with direct object iteration (was broken when
    category IDs were non-sequential)
  - include/update.php: migration is now idempotent (column-existence checks)

NEW FEATURES
  - VIDEO SUPPORT: new item_type values 'youtube' and 'vimeo'
      * New DB column: item_video_url (varchar 500)
      * Admin form: Item Type selector + Video URL field
      * parseVideoUrl() handles all common YouTube/Vimeo URL formats
      * Nivo Slider, Slick Slider and Swiper blocks all render <iframe> embeds
  - SWIPER.JS BLOCK (v11, CDN): swiperslider_block.php
      * 6 transition effects: slide, fade, cube, coverflow, flip, cards
      * Per-block settings: autoplay, autoplay speed, loop, navigation, pagination
      * Unique per-instance DOM ID; multiple blocks on one page work correctly
      * Video slide change resets iframe src to stop background playback
  - Admin list: type badge (Image / YouTube / Vimeo), inline video preview
  - Admin list: "Upcoming" status for future-scheduled slides
  - lazy loading (loading="lazy") on all <img> tags
